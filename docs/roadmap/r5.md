# R5 priorities

Recorded 2026-11-24. These are planning items, not implemented or verified features.

## Release boundary

The verified 2026-11-24 refinement batch is approved as an update to the moving
`fw-1.1.13/r4` branch. Keep R4 **untagged** while collecting user feedback in
case more bugs appear. Decide on the immutable release tag after that feedback.

After this batch, **R4 accepts critical bug fixes only**. Other fixes,
refinements and enhancements belong on R5, including non-critical UI polish.
The scoped Home/About work in this R4 batch is complete; it is not an exception
for further general native UI replacement on R4. Existing investigations and
acceptance gaps remain visible; a proven critical fix can still be considered
for R4.

## Priorities

1. **Further native UI replacement — top priority.** Audit stock construction, drawing and refresh entry points. Replace or modify stock widgets at their source where practical, rather than painting over them. Review lifecycle, visibility and ownership behavior, and measure any claimed performance improvement. Existing Home/About investigation is a starting point; it is not a completed screen-wide audit.
2. **Automatic colour matching when choosing print filament mappings.** Match requested print colours to available filament colours in the print-time picker. Define ambiguous-match behavior and retain manual choice.
3. **Assisted physical bed leveling.** Help users assess bed tilt and identify which screws to tighten or loosen. Investigate whether repeated regional probe variance can help flag a potentially loose corner or insufficient spring preload. Treat variance as evidence to investigate, not proof of a loose spring; probe noise and other causes must be considered.
4. **Assisted X/Y offset probing-height calibration.** First inspect and try the existing functionality; extend it only where needed. Guide selection of the height used for X/Y offset probing.
5. **Wizard illustrations.** Add simple graphics or pictures where they clarify physical actions or setup instructions, following the shared WM+ layout conventions.
6. **Finish openACE support.** Coordinate with the agent owning openACE, reconcile outstanding work and define integrated acceptance checks.

These items are deferred work, not R4 release gates. Only critical R4 defects remain eligible for a backport; non-critical follow-ups belong to R5.

7. **Multi-colour filament appearance.** Extend R4's saved appearance selection
   with additional colour controls and shared rendering across views. Gradient
   blends the selected colours. Co-extrusion uses sharp radial sectors clipped
   to the swatch shape: two colours split diagonally through the centre; three
   colours use three equal 120-degree sectors, whether the outline is a rectangle
   or circle. Preserve the primary hex colour for compatibility.
